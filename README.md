# 🦸 Superheroes — Jetpack Compose

Aplicación Android desarrollada con **Kotlin y Jetpack Compose**, siguiendo la práctica [Superheroes de Android Developers](https://developer.android.com/codelabs/basic-android-kotlin-compose-practice-superheroes?hl=es-419).

## 📱 Descripción

La aplicación muestra una lista de seis superhéroes, cada uno con su nombre, descripción e imagen. La interfaz utiliza componentes de Material Design 3 y permite desplazarse verticalmente para visualizar todos los personajes.

## 🚀 Funcionalidades

- Visualización de seis superhéroes.
- Tarjetas con nombres, descripciones e imágenes.
- Lista desplazable mediante `LazyColumn`.
- Interfaz desarrollada con Jetpack Compose.
- Diseño adaptable a modo claro y oscuro.
- Tipografía y colores personalizados.

## 🛠️ Tecnologías utilizadas

- **Kotlin:** lenguaje de programación.
- **Jetpack Compose:** desarrollo de interfaces declarativas.
- **Material Design 3:** componentes visuales.
- **Android Studio:** entorno de desarrollo.
- **Git y GitHub:** control de versiones.
